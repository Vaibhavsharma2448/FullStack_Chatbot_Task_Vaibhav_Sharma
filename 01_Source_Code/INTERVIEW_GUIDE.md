# Interview Notes
- Rule-based chatbot: assignment allowed predefined responses, so keyword matching is enough.
- React: used components/state for UI and chat/form/dashboard interaction.
- TypeScript: catches type mistakes and makes data structures clear.
- REST: POST creates, GET reads, PUT updates, DELETE removes.
- Validation is done on both frontend and backend because client-side checks cannot be trusted.
- Security: `.env` for secrets, Helmet, CORS, rate limiting and protected admin endpoints.
- Honest production improvements: hashed passwords, proper JWT/session expiry, role-based access, tests and deployment.
